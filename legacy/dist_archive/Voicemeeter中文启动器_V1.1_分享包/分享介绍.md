# Voicemeeter Potato 中文界面启动器 V1.1

> 给 Voicemeeter Potato 套一层中文界面，双击即用，关掉就还原。
> 不改原文件、不写注册表、不常驻后台。

**制作：杨爽工作室　|　制作工具：Marvis　|　适用：Voicemeeter Potato 8.x（64 位）· Windows 10 / 11**

---

## 一、为什么需要它

Voicemeeter Potato 功能很强，但界面全英文，混音台、设置面板、错误提示、悬停提示全是英文术语，
第一次用很容易劝退。网上的老办法是直接改 exe 汉化，而 Voicemeeter 带文件完整性校验，
改完大约 10 秒就会崩溃（0xC0000005 / 0xC000041D），只能卸载重装。

这个启动器换个思路：**在程序启动的一瞬间，把中文文本写进进程内存**。
硬盘上的 Voicemeeter 一个字节都不动，所以不会触发校验，也不会留下修改痕迹。

## 二、它能做什么

| 项目 | 说明 |
| --- | --- |
| 汉化条目 | 1043 条界面文本（ANSI 933 条 + Unicode 71 条） |
| 覆盖范围 | 主菜单 / 右键菜单 / 设置面板 / 许可证对话框 / 错误提示 / VBAN / MIDI / 录音机 / 效果器 / 全部悬停提示 |
| 改动方式 | 仅在内存中替换，**不修改原 exe** |
| 卸载方式 | 删除启动器 exe 即可，无残留 |
| 启动画面 | 5 秒品牌启动画面，可点击跳过 |
| 授权帮助 | 启动画面新增「授权与激活帮助」面板，离线查阅挑战码 / 足迹 / REGEN（V1.1） |
| 权限要求 | 需管理员权限（UAC 点击「是」） |

## 三、三步用起来

1. 确认电脑上已安装 Voicemeeter Potato 8.x（64 位）；
2. 双击「Voicemeeter8中文启动器.exe」，UAC 弹窗点「是」；
3. 等启动画面走完（或点一下跳过），Voicemeeter 就是中文界面了。

> 注意：请始终用这个启动器启动。直接双击原版 exe 仍然是英文界面。

## 四、哪些地方还是英文

主界面混音台上的固定标注（POTATO、COMP / GATE / DENOISER、INTELLIPAN、EQ、MONO / SOLO / MUTE 等）
和内置插件面板的文字，在程序里是**加密资源包里的图片**，不是文字字符串（5 个资源块约 8.3 MB，
数据熵 7.999，运行期解密后绘制）。要改只能破解加密并重绘图片，成本高且不保证成功，
所以这部分保留原样。设备名、驱动名、API 参数名等也必须留英文，否则会影响功能。

## 五、常见疑问

- **启动后还是英文？** → 没拿到管理员权限，右键「以管理员身份运行」。
- **启动约 10 秒崩溃？** → 安装目录的 exe 曾被旧汉化补丁改过，用同目录 `voicemeeter8x64.exe1` 还原后重试。
- **杀毒软件报毒？** → 注入类行为容易被误报，加信任即可。
- **能发给别人吗？** → 可以，对方需已装 Voicemeeter Potato；免费分享，请勿商用。

## 七、V1.1 新增：授权与激活帮助

启动画面多了一个按钮：**授权与激活帮助（挑战码 / 足迹 / REGEN）**。点开是一个离线帮助面板，
6 页内容分别讲授权机制、挑战码为什么会变、变了怎么救（恢复硬件足迹 / REGEN）、
REGEN 权益与购买规则、异常时怎么找官方、以及过往实际沟通结论。

面板底部还能一键打开激活日志目录、复制 `Voicemeeter_ActivationLog.dat` 的完整路径，
方便提工单时附给官方。

> 只是「查阅」，不是「破解」：本启动器不碰授权校验，也不能帮你绕过激活。
